Оцени учебный артефакт MindTree: дерево знаний или учебную сессию.

Что разбирать (в порядке приоритета):

- если `$ARGUMENTS` содержит путь к `mindtree-*.json` — дерево темы;
- если содержит путь к `mindtree.db` — сессии из базы (последние, либо конкретную);
- если аргументов нет — спроси, какой артефакт взять, и найди последние экспорты
  в `%USERPROFILE%\Downloads`.

Действуй по инструкции агента `content-reviewer`:

1. Запусти `mindtree_flutter/tool/review/bin/mindtree_review.dart` с `--out build/review`
   (LLM-судью `--judge` включай только если есть `provider-config.json` и это не мешает;
   ключи не выводить).
2. Прочитай `build/review/review-*.md`.
3. Дополни смысловым чтением: фактическая точность, сложность по уровню аудитории,
   подача (аналогии, дубли, пробелы в покрытии), согласованность бюджета времени.
4. Дай отчёт: 3–5 главных выводов по влиянию на обучение → счётчики fail/warn/info →
   конкретные правки (файл и суть) либо «дефект данных, не кода».

Не правь код и данные сам — только докладывай.
