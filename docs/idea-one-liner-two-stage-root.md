# Идея: one_liner корневого узла должен упоминать двухэтапность

## Контекст
При генерации корневого узла для темы (обзор) с параметрами **deep + solid_understanding** контент
выглядит хорошо, но в `one_liner` не отражена двухэтапность процесса (прямой + обратный ход).

Текущий `one_liner` (пример для «Диффузионные модели»):
> Генеративные модели, создающие данные путем обратного процесса удаления шума из случайного сигнала.

Процесс по факту двухэтапный (прямое добавление шума → обратное восстановление), а в `one_liner`
упомянут только обратный этап.

## Идея
Подкрутить инструкцию для `one_liner` в промпте контента (`server/src/prompts/content.ts`), чтобы
для **корневого/обзорного** узла `one_liner` кратко упоминал и прямой, и обратный этапы работы
(например: «двухэтапный процесс: зашумление данных и обратное обучение восстановлению»).

## Где править
- `server/src/prompts/content.ts` — блок `ROOT_GUIDANCE` / описание `one_liner` в `PROMPT_CONTENT`
  (строка с `one_liner — СУТЬ в одном предложении`).

## Требования
- Остаться в лимите 120 символов (`one_liner`).
- Для не-expert не вводить жаргон без пояснения (уже есть hard-антижаргон).
- Применять только к корневому/обзорному узлу — для дочерних узлов `one_liner` остаётся сутью
  конкретного понятия (двухэтапность им не нужна).

## Статус
Отложено (по решению пользователя — пока контент-генерацию не меняем).
